# Краткая справка разработчика

Основные правила работы ИИ-агентов находятся в корневом [AGENTS.md](AGENTS.md). Контекст проекта — в [docs/architecture.md](docs/architecture.md), пользовательская инструкция — в [README.md](README.md).

## Окружение

Нужны Git, Node.js 22+ и Python 3. Базовая версия Node указана в `.node-version`. Chrome нужен для браузерной проверки. Установка зависимостей и сборка сейчас не требуются.

```sh
npm start              # запуск на http://localhost:5173
npm run check          # синтаксис и тесты
npm run test:browser   # требуется отдельный тестовый Chrome; см. README
```

GitHub Actions запускает `npm run check` для push и pull request. Браузерные проверки пока запускаются отдельно. Если появятся npm-зависимости, нужно добавить `package-lock.json` и установку через `npm ci` в CI.

## Git

Основная ветка — `main`. Для отдельных задач удобно использовать `feat/название`, `fix/название` или `docs/название`. Не переписывайте общую историю и чужие изменения. В PR указывайте результат и проверки; для визуальных изменений приложите скриншот. Шаблон PR уже добавлен.

После создания пустого удалённого репозитория его можно подключить:

```sh
git remote add origin <URL-репозитория>
git push -u origin main
```

Защита `main` и обязательность CI настраиваются на Git-сервере отдельно: локальные файлы этого не включают. На GitHub имя задания CI — `checks`.

Лицензия распространения пока не выбрана; решение остаётся за владельцем проекта.
